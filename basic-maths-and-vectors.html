① Angle 'θ'

Definition: The amount of rotation of a line from its initial position, measured in terms of θ.

Planar angle

θ = length of arc / radius  →  unit: radian (S.I.), practical unit: degree

1c → one radian: when length of arc is same as radius, θ = l/r = 1 (dimensionless)

degree ⟷ radian   πc ⟶ 180°

1c = 180°/π    1° = π/180

θc = (180/π × θ)°    θ° = (π/180 × θ)c

l = θc·r   l = 2πr   ⟹ 2πr = ρcr   ⟹ π = 180°

60° = π/3 c = π/3 rad    90° = π/2 c = π/2 rad

Sign convention

θ (+ve sense) — anticlockwise  |  θ (−ve sense) — clockwise

Right triangle basics

h = √(p² + b²)    PBP : HHB (Perpendicular/Base/Perpendicular : Hypotenuse/Hypotenuse/Base — mnemonic for sin,cos,tan)

① sinθ = P/H   ② cosθ = B/H   ③ tanθ = P/B

④ cosecθ = H/P   ⑤ secθ = H/B   ⑥ cotθ = B/P

Special angle quick facts

at θ = 0°: sin0° = P/H = 0, cos0° = H/H = 1, tan0° = P/B = 0

at θ = 45°: sin45 = 1/√2, cos45 = 1/√2, tan45 = 1

(saath hi 30°,60°,90°,270°,360° ke liye bhi values nikaali gayi)

Sine° = P/H

Unit-circle construction (rotating radius) — sign of sine at each quadrant

Period (T): 90° → 180° P decreases, sinθ value decreases

180° → 270° (P III): sinθ → negative (value increases)    270° → 360° (P IV): sinθ → negative (value decreases)

Properties of Sine

  1. Periodic function: repeats after a fixed interval.
  2. Time period: 2π interval
  3. +1 ≥ sinθ ≥ −1  or  −1 ≤ sinθ ≤ +1
  4. sinθ may be increasing or decreasing depending upon the interval: (0–90°) ↑   (90–180°) ↓   (180–270°) ↓   (270–360°) ↑
  5. Sine is an odd function: sin30° = 1/2, sin(−30°) = −1/2
  6. sin(nπ) = 0 ; n is integer
  7. sin(2n+1)π/2 = ±1
  8. Sign of Sin (ASTC quadrant pattern):

Lec – 3

Tan θ = P/B

Property of Tan

  1. Periodic function
  2. Time interval: π
  3. −∞ < tanθ < ∞
  4. Odd function: tan(−θ) = −tanθ
  5. tan(nπ) = 0
  6. tan(2n±1)π/2 = not defined
  7. Sign of Tan: same ASTC pattern (+ in I & III, − in II & IV)

How to find T-ratios for bigger angle

  1. (π, 2π, 3π, 4π, 5π...) → No θ change in argument
  2. (π/2, 3π/2, 5π/2...) → Argument changes: sin⟷cos, tan⟷cot, sec⟷cosec
  3. Put sign according to ASTC rule (All-Sin-Tan-Cos, quadrants I–IV)

Formats of writing an angle: α = π/2 + θ = π − α (and similar forms for 3π/2 ± θ, 2π − θ)

Examples

sin135° = sin(180−45°) = +sin45° = 1/√2

sin225° = sin(360−180+45) = −cos45° = −1/√2

Trigonometry Identities

① sin²θ + cos²θ = 1

② 1 + tan²θ = sec²θ

③ 1 + cot²θ = cosec²θ

④ sin2θ = 2sinθcosθ

⑤ sin(A+B) = sinAcosB + cosAsinB

⑥ sin(A−B) = sinAcosB − cosAsinB

⑦ cos(A+B) = cosAcosB − sinAsinB

⑧ cos(A−B) = cosAcosB + sinAsinB

⑨ cos2θ = cos²θ − sin²θ = (cosθ+sinθ)(cosθ−sinθ)

⑩ tan(A+B) = (tanA+tanB)/(1−tanAtanB)

⑪ tan(A−B) = (tanA−tanB)/(1+tanAtanB)

⑫ tan2A = 2tanA/(1−tan²A)

Relation

A relation defines the order/dependency of D.V. on I.V.

  • y ∝ x → linear relation
  • y ∝ x² → quadratic relation
  • y ∝ x³ → cubic relation
  • y ∝ 1/x → inverse relation
  • y ∝ 1/x² → inverse square relation
  • y ∝ eˣ → exponential relation
  • y ∝ log x → logarithmic relation
  • y ∝ sinx → trigonometric relation

Function

A mathematical expression which defines an exact relationship between D.V. and I.V.

Ex: s(t) = ut + ½at², u,a = constant → displacement as a function of time

v(t) = u + at → velocity as a function of time

Linear Relationship

y ∝ x → always passes through origin, straight line. y = mx, m = proportionality const.

−∞ < m ≤ 0 → slope in II & IV quadrant    ∞ > m ≥ 0 → slope in I & III quadrant

m=0: y = 0·x (x-axis itself)    m=∞: vertical line (y-axis itself)

tanθ = mx/x = m  ⟹  θ = tan⁻¹(m)

Addition of constant: y = mx + c

Straight line having intercept at 'c'. Compare with y = mx (no intercept, passes through origin).

Quadratic Relationship: y ∝ x²

y = kx², k = proportionality const.

−∞ < k ≤ 0 → downward parabola (III & IV quad)    0 ≤ k < ∞ → upward parabola (I & II quad)

Slope Theory

tanθ = (y₂−y₁)/(x₂−x₁) = Δy/Δx ≡ slope    θ = tan⁻¹(Δy/Δx)

Slope of a straight line gives an idea about the inclination of line with x-axis.

y = mx → tanθ = y/x → y = (tanθ)x → y = mx, slope = m

Slope will remain same at each and every point in a straight line graph.

Slope at a point on curve

y = x²: slope at point "p" = tanθp — draw a tangent at that pt, its inclination with x-axis gives the slope.

Slope decreasing (↓) vs slope increasing (↑) — shown for concave-down vs concave-up sections of a curve, and for sinx: slope goes max(+ve) → 0 → max(−ve) → 0 across one period, i.e. slope(0), slope max(−ve) at π/2, slope(0) at π, slope max(+ve) at 3π/2, slope(0) at 2π.

Differentiation

Differentiation is a process of analysing change in dependent variable w.r.t. change in independent variable.

It is a tool that gives us the ability to analyse small change at each and every point — infinitesimal change in I.V. → change in D.V. ⟹ analysing = Differentiation.

dy/dx = limΔx→0 (Δy/Δx)

limΔx→0 ⟹ Δx = 0.00000...→1 (infinitesimally small, but not zero)

dy/dx = analysing change in (y) w.r.t only (infinitesimal) small change in (x).  d/dx → differentiator

d(voltage)/d(current) = dV/dI = Resistance — analysing small change in voltage w.r.t small change in current.

Lec – 9

Differentiation Rules

① Power rule

y = xⁿ  ⟹  dy/dx = nxⁿ⁻¹

e.g. y=√x → dy/dx = 1/(2√x); y=1/√x → dy/dx = −1/(2x^3/2); y=x⁹ → dy/dx=9x⁸; y=∛x → dy/dx = 1/(3x^2/3); y=1/x → dy/dx = −1/x²

② Differentiation of a constant

d(constant)/dx = 0    e.g. de/dx=0, dπ/dx=0, d(6)/dx=0

③ Differentiation of trigonometric relation

d(sinx)/dx = cosx    d(cosx)/dx = −sinx

d(tanx)/dx = sec²x    d(cotx)/dx = −cosec²x

④ ⑤ Exponential & log

d(eˣ)/dx = eˣ    d(logx)/dx = 1/x

⑥ Constant multiple rule

y = k·f(x)  ⟹  dy/dx = k(df(x)/dx)

e.g. Circle A=πr² → dA/dr = 2πr; circumference = 2πr → d/dr = 2π

Sphere A=4πr² → dA/dr = 8πr; V=(4/3)πr³ → dV/dr = 4πr²

# Differentiation in addition/subtraction

y = f(x) ± g(x)  ⟹  dy/dx = df(x)/dx ± dg(x)/dx

e.g. y = x² ± sinx → dy/dx = 2x ± cosx

# Differentiation in product (product rule)

y = f(x)·g(x) = u·v  ⟹  dy/dx = u(dv/dx) + v(du/dx)

e.g. y = x²sinx → dy/dx = x²cosx + sinx(2x)

# Division rule

y = f(x)/g(x) = u/v  ⟹  dy/dx = [u(dv/dx) − v(du/dx)] / v²

e.g. y = x²/sinx → dy/dx = [x²cosx − sinx(2x)] / x⁴

Integration

Σi=1n dxᵢ = ∫dx

It is a process of summation, or the reverse process of differentiation. It is also called anti-derivative.

Note: To add discrete values we use "Σ". e.g. Σ Mᵢ = M₁+M₂+M₃+...+M₅₀.
A process of addition of infinitesimal, continuous changes is known as integration.

Applications

  1. To calculate net change in physical quantity.
  2. Area under the curve.

dx/dt = v ⟹ dx = v·dt (small change in position in time "dt")

Σdxᵢ ⟹ ∫dx → integration of dx, gives net change in position Δx

∫v·dt → integrating velocity w.r.t time; ∫dx → Δx

Area under curve concept

Area of strip = f(x)Δx = A₁. If Δx is very very small, f(x) ≈ f(x+Δx). For ∞ no. of strips: Total area = ∫dA = ∫f(x)dx.

Mathematical Formulae (Integration)

① Power rule

∫xⁿdx = xⁿ⁺¹/(n+1) + C  (n≠−1)

∫(1/x)dx = ln x + C

e.g. ∫x⁰dx = x+C; ∫x¹dx = x²/2+C

Area = ∫x²dx = x³/3 + C  (for y=x² curve, shaded region 0 to x)

Area = ∫√x dx = (2/3)x^(3/2) + C  (for y=√x curve)

② ③ Trig & exponential

∫sinx dx = −cosx + C    ∫cosx dx = sinx + C

∫eˣdx = eˣ + C

④ Constant multiple rule

∫k·f(x)dx = k∫f(x)dx + C    e.g. ∫4x²dx = 4∫x²dx = 4x³/3 + C

⑤ Circle / Sphere examples

∫2πr dr = 2π·r²/2 + C = πr² + C  (dA = 2πr·dr, ∫dA = ∫2πr dr = πr²+C)

∫4πr²dr = dV = 4πr²dr, ∫dV = ∫4πr²dr = 4πr³/3 + C

⑤ Addition & Subtraction

y = f(x) ± g(x)  ⟹  ∫y dx = ∫f(x)dx ± ∫g(x)dx

e.g. y = x²+sinx → ∫y dx = x³/3 + (−cosx) + C = x³/3 + cosx + C

⑥ Product Rule (Integration by Parts)

y = f(x)·g(x) = I·II  ⟹  ∫y dx = I∫II dx − ∫(dI/dx · ∫II dx) dx

Order of preference: I L A T E — Inverse trigo, Log, Algebraic, Trigo, Exponent

e.g. y = x·eˣ (I=x, II=eˣ): ∫y dx = x∫eˣdx − ∫(dx/dx·∫eˣdx)dx = x·eˣ − eˣ + C

Substitution: ∫Papa(Beta)dx = ∫(Papa)dx / (dBeta/dx), Beta → linear function

e.g. ∫sin(Ax)dx = −cos(Ax)/A + C

y = (Ax+B)²  ⟹  ∫y dx = (Ax+B)³/(3A) + C

y = sin(ωt+θ)  ⟹  ∫y dt = −cos(ωt+θ)/ω + C

Definite Integration

∫ab f(x)dx = [g(x)]ab = g(b) − g(a)

|ˣ ⟶ this is not "modulus", it is just a symbol (evaluation bracket).

Example, y=x, area between x=3 to x=5:

Area = 25/2 − 9/2 = 16/2 = 8 sq unit  (matches ∫35 x dx = [x²/2]35 = 8)

Vectors

Physical Quantity: those quantities which can be measured and have some physical significance. e.g. mass, area, force, etc.

→ Scalar Quantity: physical quantity which has no direction significance, only magnitude should be significant. e.g. mass, area.

→ Vector Quantity: physical quantity which has significance of magnitude along with direction. e.g. force, velocity.

Representation of vectors

  1. Arrow representation
  2. Magnitude representation
  3. Cartesian form

Note: BA ≠ AB (direction matters — arrowhead represents direction, length represents magnitude)

Vector = Magnitude ⊕ direction    A = |A|·A

Magnitude Representation

e.g. F = 10N, 30°N of E; wind velocity (Vw) = 15 knots (SE), 45° from N towards E

Types of Vectors

  1. Co-initial vectors — two or more vectors having same initial point.
  2. Co-planar vectors — two or more vectors lying in the same plane.
  3. Co-linear vectors — two or more vectors lying along the same line.
    • Parallel vectors — same direction; angle between parallel vectors = 0°, different or same magnitude.
    • Antiparallel vectors — opposite direction; angle between antiparallel vectors = 180°, different or same magnitude.
  4. Equal vectors — same magnitude ⊕ same direction ⊕ same physical quantity.
  5. Anti / negative vectors — direction of a vector made by rotating 180° of another vector: B=−A, A=−B (B is antiparallel of A, |A|=|B|).
  6. Null vector — a vector with 0 magnitude, denoted by "•" (dot), direction = undefined (∞). e.g. 4N+4N opposing with 2N,2N: resultant = 0N.
